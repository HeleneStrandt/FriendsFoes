# Replication Code

This repository contains the replication code for the paper **“From Friends to Foes: Identity and Knowledge Exchange”** by Nadzeya Larentsyeva and Helene Strandt.

## Repository Structure

The replication workflow consists of two stages:

* **`codes/python/`** contains the Python code used to construct the analysis database. Running these scripts requires access to **Google BigQuery** and valid Google Cloud credentials. Credentials are not included in this repository and must be configured locally by the user.
* **`codes/stata/`** contains the Stata code used for the empirical analysis and for generating the results reported in the paper.

Generated tables and figures are written to the corresponding folders in **`output/`**.
